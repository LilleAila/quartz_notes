# fransk pekeord

Foran substantiv:

- ce / cet (cet foran vokal)
- cette
- ces

Ellers:

- ceci
- cela
- ça

## 7b (s. 17)

- Tu aimes cette belle chanson belge?
- Ce grand château est très célèbre.
- Cette histoire est intéressante.
- J'aime cette petite région suisse!
- Ce garçon monégasque est sympa.
- Cette jolie dialecte est difficile.
- Ce bon plat est une spécialité belge.
- C'adore ces moules!
- Cette arbre est vieux.
- Vous aimez ces traditionns régionales?

## 7c

- Cela est intéressant
- C'est à moi.
- Est-ce un plat typique belge?
- Ceci n'est pas important
- Je le dis maintenant
- Ça va bien?
- C'est une jolie ville.
