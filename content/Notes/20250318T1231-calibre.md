# calibre

## Kobo

Bruker innebygget KoboTouch-plugin, med følgende som path:

```
books/{tags:ifempty(other)}/{series:shorten(3,-,4)}/{series_index:0>2s|| - }{title:shorten(5,-,5)}
```

Velge convert to kepub.
Skru på create collections og delete empty bookshelves.

## Kindle

Bruker innebygget Kindle-plugin, med følgende som path:

```
{tags:ifempty(other)}/{series:shorten(3,-,4)}/{series_index:0>2s|| - }{title:shorten(5,-,5)}
```

(den plasserer automatick under /documents/)
