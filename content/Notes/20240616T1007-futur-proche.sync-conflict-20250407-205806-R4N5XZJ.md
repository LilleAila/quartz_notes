"Nær fremtid", brukes om ting som kommer til å skje, og skriver på formen:
**Avoir**, bøyd til subjektet + **verbet** i infinitiv

| Sujet        | **Avoir** |
| ------------ | --------- |
| J'           | ai        |
| Tu           | as        |
| Il, Elle, On | a         |
| Nous         | avons     |
| Vous         | avez      |
| Ils, Elles   | ont       |

## Eksempler:

- Je vais manger
- Tu vas partir
