# futur simple

Brukes på nesten samme måte som [[20240616T1007-futur-proche|futur proche]].

- Parler
- Je parler**ai**
- Tu parler**as**
- Il / elle / on parler**a**
- Nous parler**ons**
- Vous parler**ez**
- Ils / elles parler**ont**

- Finir
- Je finir**ai**
- Tu finir**as**
- Il / elle / on finir**a**
- Nous finir**ons**
- Vous finir**ez**
- Ils / eles finir**ont**

- Répondre
- Je répondr**ai**
- Tu répondr**as**
- Il / elle / on répondr**a**
- Nous répondr**ons**
- Vous répondr**ez**
- Ils / elles répondr**ont**

Alle verb har samme endelser. Endelsene tilsvarer bøyningen til _avoir_ i presens. Noen verb har ulik stamme:

- Parler / parler-
- Finir / finir-
- Répondre / répondr-
- Faire / fer-
- Aller / ir-
- Être / ser
- Avoir / aur-
- Pouvoir / pourr-
- Devoir / devr-
- Savoir / saur-
- Vouloir / voudr-
- Venir / viendr-
