## Example problem: Sorting

Given a sequence $A$ og $n$ integers, return a sorted sequence containing thes same integers in a non-decreasing order.

```
input: array A, integer n
for i in {1, ..., n}
    for j in {1, ..., n-1}
        if A[j] > A[j+1] then swap(A[j], A[j+1])
return A
```

Claim: Bubble sort returns a sorted array
Claim: bubble sort finishes after $O \left( n^{2} \right)$ steps
